# ThreatGraph – Dashboard, Integration & Automation

## Overview
ThreatGraph is a CTEM-based cybersecurity platform designed to continuously discover, monitor, analyze, and prioritize organizational security risks.

This project focuses on:
- Dashboard Visualization
- SIEM Integration
- Threat Intelligence
- Automation Workflow
- Alert Management

---

## Features
- Real-time monitoring
- ELK Stack integration
- Threat intelligence correlation
- Automated alerting
- Jira ticket generation
- Dashboard visualization

---

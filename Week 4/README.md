# Week 4 - Advanced SOC Operations

This folder contains the Week 4 internship task submission focused on advanced Security Operations Center (SOC) concepts and practical implementation.

---

##  Objectives

The objective of this task was to:

- Perform proactive threat hunting using system logs and network activity
- Understand SOAR (Security Orchestration, Automation, and Response)
- Conduct post-incident analysis using structured methodologies
- Simulate adversary behavior and test detection capabilities
- Analyze and preserve security evidence
- Generate SOC metrics and executive-level reports
- Perform a complete SOC workflow through a capstone project

---

- Kali Linux

- Nmap  
- Metasploit  
- VirusTotal  
- AlienVault OTX  
- Linux Logs (journalctl)  
- Draw.io (Fishbone Diagram)  
- GitHub  

---

## 🔍 Topics Covered

### 1. Threat Hunting
- Generated suspicious SSH login attempts
- Analyzed authentication logs
- Correlated logs with network traffic

### 2. Threat Intelligence
- Validated IOC using VirusTotal and AlienVault OTX
- Enriched alerts with external intelligence

### 3. SOAR Automation (Conceptual)
- Designed a playbook for automated incident response
- Simulated alert validation and response workflow

### 4. Post-Incident Analysis
- Performed Root Cause Analysis using 5 Whys
- Created Fishbone Diagram for cause identification

### 5. Evidence Collection
- Collected SSH logs
- Generated SHA256 hash for integrity verification

### 6. Adversary Emulation
- Simulated attack using Metasploit
- Mapped activity to MITRE ATT&CK techniques

### 7. Security Metrics
- Calculated MTTD, MTTR, and Dwell Time
- Evaluated SOC performance

### 8. Capstone Project
- Performed full SOC workflow:
  - Attack Simulation
  - Detection
  - Triage
  - Response
  - Analysis
  - Reporting
